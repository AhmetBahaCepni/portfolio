Internet Relay Chat

A C++ server for conversations between multiple connected clients.

C++NetworkingServer

The idea

This project explores the server side of real-time communication. Written in C++, it accepts multiple client connections and manages the messages they exchange.

Under the hood

Building it means thinking about connections as an ongoing conversation: clients arrive, send data, and leave while the server continues serving everyone else. That makes the project a practical study in networked software.
